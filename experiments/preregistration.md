# PABLA-v2 experiment preregistration — draft, NOT frozen

The full campaign must not be represented as pre-registered until reviewer
approval and a frozen tagged revision. H1 (window bounds), H2 (fork evidence),
H3 (performance), H4 (cost scheduling), and H5 (ablations) are proposed, not
confirmed. No significance threshold has been chosen from observed main data.

The current `--v2` command is a **smoke test**, not X1–X12. It uses a labeled
memory ledger and a controlled X3 fixture. Production campaigns must run
identical trace bytes and adversarial capabilities under each baseline, randomize
trial order, reset ledger state per condition, collect exact gas receipts,
record dataset SHA-256, and report failures and missing runs explicitly.
Deterministic security outcomes must be reported as a pass/fail matrix.
Stochastic timing tests require a frozen analysis plan before collection.
